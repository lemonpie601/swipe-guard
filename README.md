# 스와이프 가드 (Marinara Engine 확장)

재응답 버튼을 자꾸 실수로 눌러서 만든 확장이에요.

## 기능

- AI 응답 아래의 `< 1/1 >` 스와이프 바를 숨기고, 하단 아이콘 줄(복사·편집·삭제…) 끝에 작은 `≋ 1/1` 아이콘으로 옮겨요.
- 아이콘을 누르면 `‹ 1 / 3 ›` 작은 창이 열려요. 마지막 스와이프에서는 오른쪽 버튼이 **재응답 ›**으로 바뀌어요.
- 재응답(다음 스와이프 생성 / Regenerate)을 누르면 먼저 **"재응답 받을까요?"** 확인 창을 띄워요.
  - 기본 선택은 **취소**예요. Esc를 누르거나 바깥을 클릭해도 취소돼요.
  - 터치 기기에서는 Marinara가 원래 확인 창을 띄우므로 두 번 묻지 않아요.

## 설치

Marinara **설정 → 외부 확장**에서 이 저장소 주소를 연결하거나, 저장소의 `manifest.json`이 있는 폴더를 가져오세요.
가져온 확장은 꺼진 상태로 들어오니, 코드를 확인하고 승인한 뒤 켜 주세요.

## 참고

- 확인 창은 버튼 클릭만 막아요. 키보드 단축키나 터치 스와이프 제스처로 재응답하는 경우는 막지 않아요.
- 작은 스와이프 창에는 `role="dialog"`를 붙여 두었어요. 그래서 '확장 서랍'처럼 화면에 떠 있는 버튼을 모아 숨기는 확장이 이 창은 숨기지 않아요.

## 파일

| 파일 | 내용 |
| --- | --- |
| `manifest.json` | 확장 정보 (`full_page_access` 권한 사용) |
| `extension.js` | 아이콘 이동 + 재응답 확인 창 |
| `extension.css` | 아이콘 · 작은 창 · 확인 창 스타일 |
